# NeuroComment 1.1.4 — AI Provider Patch

Это обновление поверх NeuroComment 1.1.3.

## Изменения
- выбранный тон теперь реально добавляет отдельные правила в системный промпт;
- AI-провайдер переключается между Ollama и OpenAI API;
- OpenAI используется через Responses API, без дополнительного Python-пакета;
- в интерфейсе есть проверка OpenAI API Key и выбранной модели;
- Ollama и OpenAI имеют отдельные настройки;
- кнопка «Установить Ollama» открывает официальный загрузчик Ollama;
- кнопка «Скачать модель» запускает `ollama pull <модель>` прямо из NeuroComment;
- версия интерфейса и движка обновлена до 1.1.4.

## Как применить
Замените в существующей папке NeuroComment 1.1.3 следующие файлы:
- desktop_app.py
- config.py
- settings_store.py
- ai.py
- main.py
- requirements.txt

Папку пользовательских данных `%LOCALAPPDATA%\\NeuroComment` не удаляйте — аккаунты, настройки и Telegram-сессии останутся на месте.

## Первый запуск с Ollama
Ollama не включена внутрь NeuroComment и модель qwen3:8b не лежит в установщике.
В разделе Настройки → AI:
1. выберите «Ollama (локально)»;
2. нажмите «Установить Ollama»;
3. завершите официальный установщик;
4. нажмите «Скачать модель»;
5. после загрузки нажмите «Проверить Ollama».

## OpenAI
Выберите «OpenAI API», вставьте свой API Key и укажите модель.
По умолчанию: `gpt-5.6-luna`.

Важно: подписка ChatGPT и биллинг OpenAI API — отдельные продукты.

# Telegram Manager 2.5.1

## What's new

- Added parallel channel unsubscribe for multiple Telegram accounts.
- Each account can independently use its own channel group (Groups 1–10).
- Added per-account unsubscribe progress, status and error counters.
- FloodWait is handled independently for each account, so other accounts can continue working.
- Unsubscribe tasks are saved locally and can be resumed after application restart.
- Improved the separate "Remove channels" workflow.
- Preserved existing channel groups, Telegram accounts, settings and subscription progress.
- Russian and English interface.

## Installation

Download `TelegramManager-Setup.exe` from this release and run the installer.

Before upgrading an existing installation, creating a backup is recommended.

## Verification

Use `SHA256SUMS.txt` to verify downloaded release files.
